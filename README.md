# JasaPro Website – Advanced Version

Website jasa profesional dengan fitur:
- Dark / Light mode
- Navbar sticky + scroll effect
- Animasi scroll reveal
- Portfolio modal interaktif
- Form kontak langsung ke WhatsApp

## Cara pakai
1. Buka `index.html` di browser (perlu koneksi internet untuk Tailwind CDN).
2. Edit nomor WA di `js/main.js` → variabel `WA_NUMBER`.
3. Ganti nama, layanan, dan konten sesuai bisnis Anda.

## Struktur
```
service-website-advanced/
├── index.html
├── css/
│   └── style.css
├── js/

```
